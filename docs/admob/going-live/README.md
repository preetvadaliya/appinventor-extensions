# Going live

Test ads work without any setup. Before real users see real ads, go through this list.

{% stepper %}
{% step %}
## Get your own IDs

Create your AdMob account, app and ad units: [Set up AdMob](../setup.md).
{% endstep %}

{% step %}
## Protect your account

Add your phone as a test device **before** you paste in your real IDs:
[Switch to real ads safely](real-ads.md).
{% endstep %}

{% step %}
## Place ads the way Google allows

Check each ad against [AdMob policies](policies.md): where it appears, how often, and
whether the user chose it.
{% endstep %}

{% step %}
## Publish on Google Play

Declare the ads, fill in Data safety, and set up `app-ads.txt`:
[Publishing on Google Play](google-play.md).
{% endstep %}

{% step %}
## Know what happens in Europe

These extensions don't show a consent form, which limits ads for users in the EEA, the
UK and Switzerland: [Privacy and consent](consent.md).
{% endstep %}
{% endstepper %}
