# Support

## Ask a question

Post in the extension's topic on the
[MIT App Inventor Community](https://community.appinventor.mit.edu/t/free-admob-banner-extension/176230).
Include:

* which extension and version,
* what you expected and what happened,
* the `errorCode` and `message` from `AdFailedToLoad` or `AdFailedToShow`,
* a picture of the blocks involved.

## Report a bug

Open an issue on
[GitHub](https://github.com/preetvadaliya/appinventor-extensions/issues).

## Downloads

Every `.aix` and sample `.aia` is in the
[GitHub repository](https://github.com/preetvadaliya/appinventor-extensions), one folder
per extension.
